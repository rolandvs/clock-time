# clock-time

This repo is dedicated to clocks that show the time.

It will grow over _time_.

It is sort of a replacement for the `hello-world` program or a blinking LED. Sometimes working on a new display using embedded Linux or a Zephyr based system a demo or test was required. This could be something on the command line or using fancy graphics control like `lvgl` or `PyQt5`. In order to learn all about it, the creation of a clock contains a lot of the programming and hardware concerned elements to investigate.

So from _time_ to _time_ I will add another clock for display or embedded systems.
