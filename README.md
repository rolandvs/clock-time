# clock-time

This repo is dedicated to clocks that show the time.

It will grow over _time_.

It is sort of a replacement for the `hello-world` program or a blinking LED. Sometimes working on a new display or embedded Linux or Zephyr system a demo or test was required. This could be something on the command line or using fancy graphics control like lvgl or PyQt5. In order to learn all about it the creation of a clock contains a lot of the elements to investigate.

So from _time_ to _time_ I will add another clock for display or embedded systems.


We start out with **written language clocks** like [QLOCK-TWO](QLOCKTWO/README.md) and [BINARY CLOCK](BINARY CLOCK/README.md).

Any improvement or bug: you are free to create an issue or pull request.

Another clock called [LUDIEK](https://www.linkedin.com/feed/update/urn:li:activity:7476381688256860160/) will be added soon.
